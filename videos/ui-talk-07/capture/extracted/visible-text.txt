## 4. 목업 명세 (`mocks.jsx` + `cards.css`의 mocks 구역)

공통
- 03·04·06·07 목업과 채팅 목업 2개는 폰 300×560: `<div className="phone"><div className="scr"><div className="wm-screen">…</div></div><div className="notch" /></div>`
- 05 `SidebarMock`만 넓은 웹 창 (340 × 500, 6탄 이전 편 `pm-site`와 같은 비율): `.wm-site` 흰 바탕 + 5px `--ink` 크레파스 테두리 + radius 18, 위에 점 3개 창 막대
- `.wm-screen { position:absolute; inset:0; padding: 50px 22px 22px; display:flex; flex-direction:column; gap: 14px; }`
- 제목 막대 `.wm-ttl` (14px × 110px, `--ink-soft`) + 본문 막대 `.wm-ln` (12px, `--paper-line`)
- 강조 요소만 핑크(`--p` / `--p-deep`), 나머지는 회색 막대. 테두리 크레파스는 `::after`에 `filter:url(#wax-stroke)` (글자에는 필터 금지)
- 실제 글자는 꼭 필요한 곳에만, Pretendard 700 20~22px `var(--ink)`

### 4-1. `StepperMock` (03)
1. 위쪽 단계 줄 `.wm-steps`: 원 36px 3개를 가로선(4px)으로 연결
   - 1번 원: `var(--p-deep)` 바탕 + 흰 `✓`
   - 2번 원: `var(--p)` 바탕 + 실제 글자 `2`, 둘레에 공용 `.ping`
   - 3번 원: 흰 바탕 + `--ink-faint` 테두리 + 글자 `3`
   - 원 아래 실제 글자 `주소` / `결제` / `완료` (20px)
2. 아래 입력 칸 2개 (높이 48, 흰 바탕, 3px `--paper-line` 테두리)
3. 맨 아래 버튼 `다음` (pill, `var(--p)`)
- **이름 붙은 단계를 순서대로 거치는** 모양이 바로 보여야 해요. 쪽 번호(1 2 3 4 5 >)처럼 그리지 않아요

### 4-2. `ProgressMock` (04)
1. `.wm-ttl` + 실제 글자 `2 / 5` (22px, 오른쪽 정렬)
2. 진행 막대 `.wm-bar`: 너비 100%, 높이 16, radius 8, 트랙 `--paper-line`, 채움 40% `var(--p-deep)`
3. 질문 카드 1장 (흰 바탕, 높이 200) 안에 `.wm-ln` 3줄 + 선택지 막대 3개
4. 맨 아래 점 5개 (지름 12, 2개만 `--p-deep`)
- **얼마나 왔는지만** 보여 주고 단계 이름은 없어요 (Stepper와 구분)

### 4-3. `SidebarMock` (05, 웹 창)
1. 창 왼쪽 **세로 띠** `.wm-side` (너비 96, 높이 창 전체, `var(--p)` 연한 바탕 = `color-mix(in srgb, var(--p) 45%, white)`)
   - 안에 아이콘 자리 원 20px + `.wm-ln` 짧은 막대 4줄, **둘째 줄만** `var(--p-deep)` 바탕 강조
2. 오른쪽 본문: `.wm-ttl` + `.wm-ln` 3줄 + 2칸 카드
3. 띠 둘레에 공용 `.ping`
- **눌러서 열지 않아도 늘 떠 있는** 모양이에요. 화면을 덮거나 밀려 나오는 그림자·어두운 바탕은 넣지 않아요 (1탄 Drawer와 구분)

### 4-4. `BackButtonMock` (06)
1. 위쪽 앱 바 `.wm-appbar` (높이 52): 왼쪽 `‹` 화살표 버튼 (원 40px, `var(--p)` 바탕, `--p-deep` 선, 글자 아님 → 선으로 그림), 가운데 실제 글자 `상품 상세`
2. 화살표 둘레에 공용 `.ping` + 공용 `.cursor`
3. 아래 상품 사진 자리 네모 (높이 180) + `.wm-ln` 3줄
- 지나온 길(`홈 > 상의 > ...`) 줄은 넣지 않아요 (2탄 Breadcrumb과 구분)

### 4-5. `FabMock` (07)
1. `.wm-ttl` + 목록 행 5개 (높이 44, 작은 네모 + `.wm-ln`)
2. 화면 오른쪽 아래 **동그란 버튼** `.wm-fab` (지름 64, `var(--p-deep)` 바탕, 흰 `+` 선, 그림자 `0 6px 0 var(--ink-faint)`), 목록 위에 떠 있음
3. 버튼 둘레에 공용 `.ping`
- **목록 위에 떠서 늘 같은 자리에 있는** 버튼이 바로 보여야 해요

### 4-6. `PageNumMock` (02장 AI 1, 미니)
- 폰 화면 위에 `.wm-ln` 4줄, 아래에 실제 글자 `1 2 3 4 5 >` 쪽 번호 줄 (둘째 숫자만 `var(--p)` 동그라미)
- 4탄 `PaginationMock`을 import 하지 말고 이 편 `wm-`로 그려요

### 4-7. `DrawerOpenMock` (02장 AI 2, 미니)
- 폰 화면 전체를 어둡게(`rgba(61,53,83,.35)`) 덮고, 왼쪽에서 흰 패널(너비 60%)이 밀려 나온 모양, 패널 안 `.wm-ln` 4줄
- 1탄 Drawer 목업을 import 하지 말고 이 편 `wm-`로 그려요

## 5. 장별 명세

> `HL("x")` = `<span className="hl">x</span>`, `B("x")` = `<b>x</b>`, `<br>` = `<br />`. 줄바꿈 위치까지 확정이에요.

### 01 · 커버 (`cards/Cover.jsx`)

| 자리 | 값 |
|---|---|
| 제목 `h1.display.wy-cover-title` | `AI가 알아먹는<br>{HL("UI 용어집")} 7탄` |
| 부제 `p.wy-cover-sub` | `AI한테 설명하다 지친<br>나를 위한 단계와 길을 보여주는 UI 5개` |
| 나머지 | blob, 점선 루트, X 표시, 별 2개, `card-head` 6탄 그대로 |

- 형광펜: **"UI 용어집"**
- 완료 기준: 6탄 커버와 나란히 놓았을 때 위치·크기가 같고 "7탄"·부제만 다름. 부제가 2줄이고 잘리지 않음 (넘치면 부제 36px)

### 02 · 이런 상황이 답답하시죠 (`cards/Chat.jsx`)

| 자리 | 값 |
|---|---|
| 제목 | `이런 상황이 답답하시죠,,` |
| 나 1 | `주소, 결제, 완료 순서로<br>단계 보이게 해줘` (캡션 인용과 같은 문장) |
| AI 1 | 미니 `<PageNumMock />` + `(1 2 3 4 5 쪽 번호를<br>달아 옴)` |
| 나 2 | `왼쪽에 메뉴가<br>늘 떠 있게 해줘` |
| AI 2 | 미니 `<DrawerOpenMock />` + `(눌러야 밀려 나오는<br>메뉴를 만들어 옴)` |
| 나 3 (마지막) | `아니 그게 아니라,,` |
| 결론 카드 | `{HL("Stepper, Sidebar")}라고<br>한 마디면 끝났을 일` |

- 순서: 나 1 → AI 1 → 나 2 → AI 2 → 나 3
- 말풍선 글자는 따옴표 없이, AI 쪽은 괄호 안 장면 설명
- **주석 없음**: 실제/예시 장면 여부 주석을 넣지 않아요
- 대화 묶음 `.wy-chat-thread { margin: 30px; display: flex; flex-direction: column; gap: 50px; }`, 반복 표시 없음
- 크기는 6탄 값 그대로
- 형광펜: **"Stepper, Sidebar"**
- 완료 기준: 말풍선 2줄 이하, 미니 목업 두 개가 서로 다르게 보임 (쪽 번호 / 밀려 나온 메뉴), 결론 카드 y=1230 위

**03~07 공통**
- 형광펜: 없음 (강조는 `<b>`만)
- 완료 기준
  - `when` 한 문장이 1줄 (넘치면 2줄까지)
  - before/after 박스 글자가 오른쪽 칸 안에서 넘치지 않음
  - 팁 카드가 1~2줄, y=1230 위에서 끝남
  - 목업에서 강조 요소(이름 붙은 단계 / 채워진 막대 / 늘 떠 있는 세로 띠 / 왼쪽 위 화살표 / 떠 있는 + 버튼)가 바로 보임
  - 03 ↔ 04는 짝 장이라 나란히 놓았을 때 레이아웃 위치가 같음
